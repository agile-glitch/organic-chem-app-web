Organic chemistry app - website version

Upload the contents of this folder to any static web host (GitHub Pages, Netlify, your own server), keeping the
folder structure, and open index.html. No server-side code is needed. To show it inside a Squarespace or Google Sites
page, embed its address in an iframe, e.g.
  <iframe src="https://YOUR-ADDRESS/index.html" style="width:100%;height:900px;border:0"></iframe>

Left out on purpose: lecture slides, the PubChem/CAS compound library, RetroChimera (runs on a local GPU), reactions
without a confirmed licence and lab experiments whose sources state no licence. Keep credits.html online: the Open
Reaction Database data require attribution and share-alike (CC BY-SA 4.0), and several experiments are CC BY-NC-SA,
so the site must not be used commercially without checking those sources.
